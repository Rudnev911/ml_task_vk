# ml_task_vk

Тестовое задание по машинному обучению для VK. 

Данный репозиторий содержит решение задачи машинного обучения, включающее полный цикл разработки: от предварительной обработки данных и обучения модели до создания API для инференса.

## 🗂 Структура проекта

Проект логически разделен на три основных этапа:

1. **Подготовка данных (Data Preparation)**
   - Скрипты и ноутбуки для загрузки, очистки и предобработки сырых данных.
   - Генерация признаков (Feature Engineering) и подготовка датасетов для обучения и тестирования.
2. **Обучение модели (Model Training)**
   - Выбор архитектуры и подбор гиперпараметров.
   - Обучение модели, валидация и сохранение весов (артефактов модели) для дальнейшего использования.
3. **Инференс / API (Inference)**
   - Обертка обученной модели в REST API (например, с использованием FastAPI или Flask).
   - Прием входящих запросов, обработка данных и возврат предсказаний модели.

## ⚙️ Установка и запуск

Запустить проект можно двумя способами: локально с использованием Python и виртуального окружения, либо через Docker.

### Способ 1: Локальная установка (requirements.txt)

Убедитесь, что у вас установлен Python 3.8+ (или выше).

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Rudnev911/ml_task_vk.git
   cd ml_task_vk
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows
   ```

3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустите API (пример для FastAPI):
   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

### Способ 2: Использование Docker (Рекомендуемый)

Убедитесь, что у вас установлены Docker и Docker Compose.

1. Клонируйте репозиторий и перейдите в папку:
   ```bash
   git clone https://github.com/Rudnev911/ml_task_vk.git
   cd ml_task_vk
   ```

2. Соберите и запустите контейнер:
   ```bash
   docker build -t ml_task_vk .
   docker run -p 8000:8000 ml_task_vk
   ```
   *(Или используйте `docker-compose up --build`, если в проекте есть `docker-compose.yml`)*

## 🚀 Использование API

После запуска приложения, API будет доступно по адресу `http://localhost:8000`.
Документацию к API (Swagger UI) обычно можно найти по адресу: `http://localhost:8000/docs`.

**Пример запроса к API (cURL):**
```bash
curl -X POST "http://localhost:8000/predict" \
     -H "Content-Type: application/json" \
     -d '{"feature1": "value1", "feature2": 123}'
```
